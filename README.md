# Хроники Руси

«Хроники Руси» — одиночная Action RPG в жанре action roguelite. Игра создаётся в формате 2.5D-изометрии с трёхмерными моделями и использует славянское фэнтези на основе Руси X–XI веков.

Версия редактора: **Unity 6000.2.5f1**.

## Текущее состояние прототипа

- новая Unity Input System;
- управление с клавиатуры и геймпада;
- перемещение через `CharacterController`;
- движение относительно камеры;
- плавные ускорение, торможение и поворот;
- гравитация и столкновения с препятствиями;
- перспективная изометрическая камера с плавным слежением;
- State Machine с рабочими состояниями Idle и Move;
- заготовки состояний Dodge, Attack, Hurt и Death;
- адаптер для будущего Animator.

## Запуск прототипа

1. Добавьте корневую папку проекта в Unity Hub через **Add project from disk**.
2. Откройте проект в Unity `6000.2.5f1` и дождитесь окончания импорта.
3. Откройте сцену `Assets/_Game/Scenes/Prototype_PlayerMovement.unity`.
4. Нажмите **Play**.

Если сцена отсутствует, выберите **Chronicles of Rus → Build Prototype Scene**, затем откройте созданную сцену.

Управление перемещением: WASD, стрелки или левый стик геймпада.
