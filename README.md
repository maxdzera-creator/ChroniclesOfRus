# Хроники Руси

Одиночная Action RPG с элементами roguelite, изометрической камерой и сеттингом славянского фэнтези, вдохновлённым Русью X–XI веков.

> Проект находится на ранней стадии разработки. Текущая версия представляет собой технический прототип основных систем игрока.

## О проекте

«Хроники Руси» разрабатывается как атмосферное приключение в формате 2.5D: трёхмерные персонажи и окружение сочетаются с фиксированной изометрической перспективой. В основе проекта — динамичное управление, модульная архитектура игровых состояний и постепенное развитие боевых и roguelite-механик.

**Технологии:**

- Unity `6000.2.5f1`;
- C#;
- Unity Input System;
- `CharacterController`;
- собственная State Machine игрока.

## Уже реализовано

- управление с клавиатуры и геймпада;
- перемещение относительно камеры;
- плавные ускорение, торможение и поворот персонажа;
- гравитация и столкновения с препятствиями;
- перспективная изометрическая камера с плавным слежением;
- State Machine игрока с состояниями Idle, Move и Dodge;
- перекат с настраиваемой дистанцией, длительностью и cooldown;
- фиксирование направления переката и окно неуязвимости для будущей боевой системы;
- заготовки состояний Attack, Hurt и Death;
- адаптер для будущего подключения Animator;
- инструмент автоматической сборки тестовой сцены.
- архитектурная версия лёгкой атаки;
- активное окно удара и поиск целей;
- cooldown атаки;
- отладочная визуализация области удара.

## Запуск

### Требования

- Unity Hub;
- Unity Editor `6000.2.5f1`.

### Запуск прототипа

1. Клонируйте репозиторий или скачайте его исходный код.
2. В Unity Hub выберите **Add project from disk** и укажите корневую папку проекта.
3. Откройте проект в Unity `6000.2.5f1` и дождитесь завершения импорта.
4. Откройте сцену `Assets/_Game/Scenes/Prototype_PlayerMovement.unity`.
5. Нажмите **Play**.

Если тестовая сцена отсутствует, создайте её через меню Unity:

`Chronicles of Rus → Build Prototype Scene`

## Управление

| Действие | Клавиатура | Геймпад |
| --- | --- | --- |
| Перемещение | `WASD` или стрелки | Левый стик |
| Перекат | `Space` | Button East |

Остальные действия присутствуют в конфигурации Input System, но соответствующие игровые механики пока не реализованы.
