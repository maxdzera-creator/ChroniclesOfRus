# Хроники Руси — Game Design Document

## Название и краткое описание

**«Хроники Руси»** — одиночная Action RPG с забегами в жанре action roguelite. Игрок управляет героем в мире славянского фэнтези, проходит комнаты, сражается с противниками и развивает персонажа во время забегов и между ними.

Документ фиксирует текущее направление проекта. Не отмеченные как решённые детали могут измениться в ходе прототипирования.

## Основные параметры

- Жанр: одиночный action roguelite.
- Движок: Unity.
- Визуальный формат: 2.5D-изометрия с 3D-моделями.
- Сеттинг: славянское фэнтези на основе Руси X–XI веков.
- Управление: в реальном времени, с поддержкой клавиатуры и геймпада.

## Основной игровой цикл

Предварительный цикл:

1. Подготовка героя к забегу.
2. Прохождение последовательности комнат.
3. Сражения и получение рун, благословений и временных усилений.
4. Встреча с более сложными противниками и боссами.
5. Завершение забега победой или смертью.
6. Использование метапрогрессии перед следующим забегом.

Продолжительность забега, структура комнат и правила сохранения ресурсов пока не определены.

## Управление

Текущий прототип поддерживает:

- перемещение на клавиатуре: WASD или стрелки;
- перемещение на геймпаде: левый стик;
- направление движения относительно камеры;
- плавные ускорение, замедление и поворот персонажа.

В Input System подготовлены действия Dodge, Light Attack, Heavy Attack, Ability, Interact и Pause. Их игровая реализация относится к следующим этапам.

## Система состояний персонажа

Персонаж использует расширяемую конечную машину состояний:

- `Idle` — ожидание ввода;
- `Move` — движение относительно камеры;
- `Dodge` — заготовка для переката;
- `Attack` — заготовка для атак;
- `Hurt` — заготовка для реакции на урон;
- `Death` — заготовка для смерти.

Ввод, перемещение, анимация и управление состояниями разделены между отдельными компонентами.

## Будущие механики

- перекат;
- ближний бой;
- здоровье, получение урона и смерть;
- обычные противники и боссы;
- процедурные или вариативные комнаты;
- руны и способности;
- благословения;
- развитие между забегами;
- оружие и характеристики персонажа.

## Решённые вопросы

- Игра является одиночным action roguelite.
- Используются Unity и C#.
- Визуальный формат — 2.5D-изометрия с 3D-моделями.
- Основное перемещение реализовано через `CharacterController`.
- Используется новая Unity Input System.
- Поддерживаются клавиатура и геймпад.
- Камера перспективная, изометрическая и не вращается игроком.
- Архитектура персонажа основана на модульных компонентах и State Machine.
- Сеттинг опирается на славянское фэнтези и Русь X–XI веков.
